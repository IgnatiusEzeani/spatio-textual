# spatio-textual documentation

This directory is for documentation of the reusable `spatio-textual` Python package and general application.

Project-specific protocols, benchmark records, workshop material and conference results belong under `projects/<project>/`. Spatial Humanities 2026 material is maintained under [`projects/sh2026/`](../projects/sh2026/).

The package/documentation boundary follows one rule: material that remains useful independently of a particular project belongs here; project-specific experimental configuration and evidence belongs with that project.
